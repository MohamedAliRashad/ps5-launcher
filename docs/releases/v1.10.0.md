# PS5 Launcher v1.10.0: downloads, installation and a refreshed Library

## What's new

- **Background downloads:** explicitly look up magnet metadata, review files and size, then start downloading. Manage progress, pause/resume, cancel and history from Downloads (`Ctrl+D`).
- **Download → Install → Play:** completed downloads can be installed with a separate confirmation. Supported archives and loose folders are staged and validated before being added to the library. Existing games are never overwritten and original downloads are kept.
- **Seeding on completion:** finished downloads share by default while the launcher is open. Disable **Settings → Seed completed downloads**, or use **Stop seeding** for an individual transfer. Uploads are capped at 128 KiB/s across the session.
- **One card per game:** the English RuTracker catalog retains all 614 release topics, while editions and versions are grouped in the Library. The Game Hub release selector preserves access to each exact release.
- **Responsive Library:** saved Comfortable/Compact density, combined status/genre/search filters, seven-option sort dropdown, clearer two-line titles and compact green/red peer captions. Density changes retain the scroll anchor.
- **Refreshed branding:** an original white/electric-blue P5 emblem and a calmer welcome screen.

## Important behavior and limitations

- Downloads require explicit confirmation. Closing the launcher stops network transfers and seeding; reopening never resumes them automatically. Installation and game launch are separate explicit actions.
- Only obtain and share content you are authorized to use. Magnet discovery and transfers expose your IP address to trackers and peers.
- Catalog peer counts are dated website snapshots, not live swarm totals. Catalog reload still reads local JSON; online per-game peer refresh is not included in this release.
- Archive support depends on system `libarchive.so.13`. Password-protected archives, PKG decryption, and update/DLC merging are unsupported. Structural validation does not guarantee authenticity or complete archive checksum verification.

## Validation

54 Rust tests passed, including generated loopback download/seeding tests and installation safety checks. Native Library, Settings persistence, download/install UI, and all 614 catalog-topic preservation checks passed using isolated profiles and authored fixtures. No real game payloads were downloaded or executed for testing.

## Installation and updates

Download and extract **ps5-launcher-linux-x86_64.tar.gz**, then run the included installer. A SHA-256 checksum is provided alongside the archive. Existing installations with automatic updates enabled will receive this version through the normal updater. Restart to load the new version.
